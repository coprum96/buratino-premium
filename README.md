# Золотой Детектор

Образовательная игра о защите от финансового мошенничества для подростков 14–17 лет.

Версия игры: `2.0.0`  
Версия сценария: `2.0.0`  
Версия банка заданий: `2.0.0`  
Схема сохранения: `2`

## Запуск

```bash
npm install
npm run dev
```

Игра: `http://localhost:5173`

```bash
npm test          # unit, integration, a11y
npm run test:e2e  # Playwright
npm run build     # production
npm run badge:demo     # экран разблокировки «Холодная голова»
npm run video:preview  # 40-секундный ролик, http://localhost:5174
npm run video:render   # запись 1920×1080 в outputs/gold-detector-launch.webm
```

Промокод полного доступа: `buratino`. Главы после активации всё равно открываются по порядку.

## Архитектура состояния

Состояние живёт в `src/store/gameStore.ts` (Zustand + persist).

Сохраняется после каждого значимого действия в `localStorage` (`gold-detector-save`):

- `completedChapters` — уникальные главы, максимум 8;
- `completedActivities` — уникальные учебные этапы, максимум 14 (`ch0-story` … `ch6-quiz`);
- `currentLevel`, `currentDialogue`, `phase`;
- `wisdom`, `coins`;
- `chapterQuizScores`, `postTestScore`;
- `storyChoices`, `finaleDecision`;
- `achievementUnlocks` (id → время) и служебные сигналы достижений;
- `accessStatus` и промокод;
- версии игры, сценария, банка заданий и схемы сохранения;
- случайный `participantId`.

Старые сохранения с массивом `completedLevels` мигрируют в `src/lib/storage.ts`: дубли глав схлопываются.

Повтор главы не увеличивает прогресс и не начисляет награды.

«Начать заново» всегда спрашивает подтверждение и сбрасывает прогресс, монеты, промокод и результаты.

## Счётчики

- На карте: «Пройдено глав: N из 8».
- В панели: отдельные метрики «главы 0–8» и «учебные этапы 0–14».
- 14 этапов — сюжет и проверка глав 1–7. Глава 8 и независимый тест — итог.

## Scoring

Правила в `src/lib/scoring.ts`:

- мудрость ограничена 0–100;
- монеты не уходят ниже 0;
- повтор главы не даёт баллы;
- финальный балл = тесты 40% + сюжет 25% + монеты 20% + независимые проверки 15%;
- сертификат только если финал не проигрышный, монеты > 0, мудрость ≥ 60 и независимая проверка ≥ 70%.

Три финала (`src/lib/endings.ts`): безопасный отказ, пауза, потеря денег с планом действий. Если монеты отданы, текст не говорит, что они «в безопасности».

## Калькулятор

Чистая модель: `src/lib/calculator.ts`.

- займ считает долг и переплату, не «инвестиционный доход»;
- инвестиции отделяют вложено / получено / комиссии / потери;
- MLM отделяет взносы, lock-up и выводимый остаток;
- нули, отрицательные, нечисловые и слишком большие значения отклоняются.

## Исследовательский режим

По умолчанию выключен и не меняет обычную игру.

```
VITE_RESEARCH_MODE=true
VITE_RESEARCH_WAVE=immediate   # или delayed
VITE_RESEARCH_SEND=false
```

События пишутся локально только после явного согласия. Нет ФИО, email и телефона — только случайный participant ID.

Формат экспорта: `src/lib/research/events.ts` → `exportResearchEvents()`.

Считаемые метрики: `src/lib/research/metrics.ts`  
Независимый банк: `src/data/assessmentBank.ts`  
Материалы для группы сравнения: `src/lib/research/staticMaterials.ts`
